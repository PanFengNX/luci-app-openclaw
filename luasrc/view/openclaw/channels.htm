消息渠道

微信

使用官方插件 @tencent-weixin/openclaw-weixin-cli 安装。安装前会自动检查 python3、目录权限与 ilinkai.weixin.qq.com 连通性。若提示缺少 python3，OpenWrt 24.10+ 执行 apk add python3-light，更早版本执行 opkg update && opkg install python3-light。
扫码流程：点击「登录账号」→ 打开输出的链接 → 微信扫一扫 → 页面提示成功后重启网关 → 给网关发一条消息测试。

其他渠道（Telegram / 飞书 / Discord / Slack …）

常用：channels login --channel telegram、channels login --channel feishu、channels login --channel discord。也可在「命令行」页执行任意 openclaw 子命令。
