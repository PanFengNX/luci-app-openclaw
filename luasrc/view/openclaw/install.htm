运行环境与安装

建议选数据盘挂载点下的目录，例如 /mnt/<磁盘>/OpenClaw；不要选 /overlay、/rom 等系统分区。
OpenClaw 程序本体固定装在 <安装目录>/openclaw，与数据分开存放 —— 卸载时只删程序、保留会话与凭据。
需要把程序与数据分开存放时，请在 SSH 里 uci set openclaw.main.openclaw_dir=... 后重新安装。
