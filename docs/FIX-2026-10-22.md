## 四个问题怎么修的

### 1. 备份列表在含空格的目录下失效

修法：`cmd_list` 不再用命令替换取文件列表。

```sh
# 前
for f in $(ls -1t "$dir"/openclaw-backup-*.tar.gz 2>/dev/null); do

# 后
{
    for f in "$dir"/openclaw-backup-*.tar.gz; do
        if [ -f "$f" ]; then
            printf '%s\t%s\n' "$(date -r "$f" +%s 2>/dev/null || echo 0)" "$f"
        fi
    done
} | sort -rn 2>/dev/null | while IFS="$(printf '\t')" read -r ts f; do
```

三个关键点：
- **glob 展开不按空白分词**，路径里的空格原样保留
- **排序键用 mtime 数值**，与原来 `ls -1t` 语义一致。改成按文件名里的时间戳
  会退化：手工放进来的 `openclaw-backup-manual.tar.gz` 会按字典序冒充"最新"
- **TAB 分隔**，不能按空格切（路径里有空格）

### 2. API Key 可经 GET 进访问日志

修法：`api_apply` 加两道检查。

```lua
if not is_post() then
    out({ ok = false, error = "请使用 POST 提交" })
    return
end
if query_has_secret() then
    out({ ok = false, error = "凭据不能放在 URL 查询串里，请用表单提交" })
    return
end
```

第二道是复查提出的：只挡 GET 不够，`http.formvalue()` 同时读 body 与 query，
所以 `POST ...?apikey=` 仍能生效并落日志。`query_has_secret()` 按键值对解析
`QUERY_STRING`，命中 `apikey/pass/password/code/secret/token` 就拒绝。

### 3. 备份下载整份进内存

修法：照 `api_export` 改成 64KB 分块，并区分 EOF 与 I/O 错误。

```lua
while true do
    local chunk, err = fh:read(EXPORT_CHUNK)
    if not chunk then
        if err then io.stderr:write(...) end
        break
    end
    http.write(chunk)
end
```

同时加了 `Content-Length`（避免分块传输）与 `Cache-Control: no-store`。

### 4. provider id 含空格出幽灵条目

修法：进 `for id in $all` 之前过滤形状。

```sh
all="$(... | awk '
    /^[A-Za-z0-9][A-Za-z0-9_.-]*$/ { if (!seen[$0]++) print; next }
    { printf "models.sh: 跳过不合规的 provider id：%s\n", $0 > "/dev/stderr" }
')"
```

用 awk 而不是 `grep -E`：精简版 busybox 可能没编进 egrep 别名。
被丢弃的 id 落 stderr，用户能在日志里查到"我的 provider 为什么不显示"。

## 修的过程中自己引入的 3 个 bug（都已修）

| 问题 | 后果 | 怎么发现的 |
| --- | --- | --- |
| `EXPORT_CHUNK` 声明在 1493 行，1021 行就用了 | Lua 5.1 下拿到全局 nil → `fh:read(nil)` 退化为按行读 → 二进制被读坏 | 复查 B 点追问，我核对行号发现 |
| `is_post`/`query_has_secret` 加在 1053 行，`api_apply` 在 394 行 | 调用时 `attempt to call a nil value`，整个端点 500 | 加完立刻 grep 行号发现，同类错误第二次 |
| `gsub("+", " ")` | `+` 是模式量词，开头就用量词 → `malformed pattern` | 复查前自查发现 |

前两个是同一个根因：**文件后部新加函数，没检查前面的使用点**。
