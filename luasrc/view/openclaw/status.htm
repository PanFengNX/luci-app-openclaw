检测到已有 OpenClaw 安装

  

    在本机其它位置发现了可用的 OpenClaw 安装 / 数据目录。两种处理方式：

    关联：只把本插件配置指向它，不复制任何文件（两边共用同一份数据）。

    迁移：把内容复制到本插件目录，源目录保持不动，确认无误后可自行删除。

    体积一栏是数据目录的大小，不含程序本体与 Node 运行时；迁移所需空间会比它更大。
