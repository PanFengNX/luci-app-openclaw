# 更新日志

本文件记录 luci-app-openclaw 的版本变更，格式参考 Keep a Changelog。
版本按倒序排列，最新的在最上面。

## 1.7.0

### 新增

- 百度网盘云备份：在「备份与恢复」页按三步引导完成 —— 安装网盘组件（按架构自动下载
  arm64 / amd64 静态二进制）、登录百度账号（获取授权链接 → 粘贴授权码）、
  手动或定时备份到网盘并可从云端恢复。
- 云端备份加密：可设置口令，上传前用 AES-256-GCM 加密（口令只保存在本机，不上传）；
  恢复加密备份时需要输入口令。
- 定时备份：可设每天/每周、具体时间、保留份数；只清理符合命名规则的备份文件。
- 设置下新增「更新说明」页，展示本文件的内容。

### 变更

- 下线「关联已有安装」，只保留「迁移」：统一在本插件自己的目录下运行，避免两套目录
  共用同一份配置导致行为不一致。
- 备份与恢复仍为顶层菜单，不放在「设置」子菜单里。

### 修复

- `state_dir` 被覆盖时，CLI 与网关会读写不同目录里的配置与 `.env`（表现为改了模型/
  端口不生效、API Key 写了仍报未配置）。现在由 lib.sh 统一导出
  `OPENCLAW_STATE_DIR` / `OPENCLAW_CONFIG_PATH`，init 脚本也按 state_dir 推导。
- init 脚本对 state_dir 的递归 chown 增加了符号链接与系统路径校验。

## 1.6.0

- 新增：自动清理 OpenClaw 2026.10 已删除的 `gateway.controlUi` 三个旧键（旧版 iStoreOS openclawmgr 会反复写回，导致网关拒绝启动）。
- 新增：备份操作记录，写入 `/var/log/openclaw-backup.log`。
- 新增：状态页显示 OpenClaw 新版提示，并支持一键更新。
- 改进：界面改版 —— 两列布局、版本药丸、地址复制按钮、空状态占位。
- 文档：README 补充与 iStoreOS openclawmgr 的共存说明。

## 1.5.0

- 变更：程序目录改为只读，固定为 `<安装目录>/openclaw`。
- 新增：`/usr/bin/openclaw` 命令行入口（root 调用时自动降权）。
- 修复：busybox 没有 `timeout` 时自动退化，不再直接失败。
- 修复：安装 / 操作锁加固（僵尸进程与 pid 复用判定），并新增 `unlock` 子命令。
- 变更：备份与恢复独立成页。
- 变更：Node 源去掉 glibc 选项。
- 改进：三个修复按钮合并为「体检 + 一键修复」。
- 改进：安装日志增加阶段进度，并在安装完成后自动启动。
- 新增：模型页支持按上游 `/models` 拉取模型 ID。
- 变更：菜单重组。
- 新增：设备配对一键批准。

## 1.4.0

- 明暗主题自适应：半透明中性色 + CSS 变量，跟随 LuCI 主题。
- 状态页信息层次重组：状态徽章进入标题行，键值分组，按钮分组。
