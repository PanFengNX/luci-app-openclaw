# 更新日志

版本按倒序排列，最新的在最上面。

## 1.8.21

- 网关不再「崩几次就彻底放弃」：`respawn` 改为永不放弃（退避到 1 小时一次）。
- 停止超时从 procd 默认的 5 秒放宽到 30 秒，给插件留收尾时间。
- 启动前自检：若上次日志显示状态库 schema 落后，自动执行一次 `doctor --fix --force`
  （每次开机最多一次）。
- 新增 `main.core_dumps` 开关（默认 0）：开启后允许生成 core dump 到 `<安装目录>/logs/`。

## 1.8.20

- 修复模型页三颗状态标记误报：插件没装却显示「插件已装」、Key 没配却显示「已有 Key」。
- 移除「手动输入模型 ID」按钮 —— 模型清单会自动拉取，内置服务商不需要手填。
- 修复手填框的旧值在切回内置服务商后仍覆盖下拉选择。

## 1.8.19

- 修复加密云端备份在缺少 `od` 的设备上必然失败（文件头校验不再依赖 `od`）。
- 安装器的架构校验改为只在没有 sha256 可核对时才做，不再因为缺 `od` 打出无意义的警告。
- 安装日志的下载进度不再排在「下载地址」之前。

## 1.8.18

- 修复云端列表在远端目录不存在时仍报错：百度网盘返回的措辞是「找不到指定的文件或目录
  （错误码 -9）」，1.8.17 只匹配了「不存在」，仍然漏掉。

## 1.8.17

- 修复云端备份列表在**从未上传过**时显示「读取云端列表失败」——远端目录只在首次上传时创建，
  这种情况应显示「云端暂无备份」。
- 云端列表失败时显示具体原因（组件未装 / 未登录 / 目录不存在等），不再只有一句"失败"。
- 修复「版本列表来自国内镜像」被当成错误显示成红字 + 重试按钮；现在改为中性提示，
  不影响「已是最新」的判断。

## 1.8.16

- **移除「迁移」页**。要把旧安装搬过来，请用「备份与恢复」：旧环境创建备份 → 新环境恢复。
  程序本体与 Node 运行时需在新环境重新安装。
- 随之删除后端 `migrate` / `migrate-start` / `migrate-poll` / `browse` / `discover`
  子命令与相关端点。

## 1.8.15

- 迁移目录浏览器：增加「显示隐藏文件夹」开关（OpenClaw 数据目录 `.openclaw` 因此可选）。
- 迁移目录浏览器：增加挂载点快捷跳转，不必从 `/` 一层层点下来。
- 迁移源目录可直接粘贴绝对路径，不再只能通过浏览选择。
- 微信插件安装改为显式指定 npm 源，不再受系统 npmrc 影响。

## 1.8.14

- 备份列表：安装目录含空格时备份页显示为空，已修复。
- 模型列表：修复下拉框出现 `found.` 等无效条目。
- 百度网盘：修复"检查更新"总是提示无法连接下载源。
- API Key：保存密钥改为只接受表单 POST，不再接受 URL 参数。
- 备份下载：改为分块传输，大备份不再占满内存。

## 1.8.13

- 修复审计发现的 4 个问题：备份列表、密钥提交方式、下载内存、模型过滤。

## 1.8.12

- 入口脚本移到 `/usr/libexec/openclaw/cli.sh`，不再沿用 iStoreOS 的目录名；升级时自动清理旧文件。
- 备份「校验」增加内容摘要：条目数、会话数、工作区文件数。

## 1.8.11

- 版本升级增加进度日志框，进入页面时若后台有升级会自动接管。
- 日志只渲染最后 200 行，完整内容仍在「设置 · 安装」页。

## 1.8.10

- 修复模型页服务商下拉为空：建表不再启动 CLI，前端先用内置清单立即渲染。
- 修复「检查更新」永远报无法连接：改为从新到旧探测、命中即停。
- 修复备份文件名折成三行。
- 「校验」改为报告备份内容，而不只是"是否安全"。

## 1.8.9

- **修复升级后备份设置被清回默认值**：默认配置移到 `/usr/share/openclaw/config.default`，已有配置不再被覆盖。
- 运行环境信息并入「设置 · 安装」，与安装按钮同页。
- 版本升级改为"有新版本才提示"，不再列出全部历史版本。
- 自定义 Provider 时收起模型下拉，只留手填框。

## 1.8.8

- 修复「当前生效」显示成整段报错，改为直接读配置文件。
- 备份页进入时自动检查组件更新。

## 1.8.6

- 迁移改为目录浏览器，逐级选择源目录，支持空格与中文。
- 版本升级：单次下载上限 20 秒、整链 60 秒，前端按调用放宽超时。
- npm 取数统一走代理；官方源不通时自动回退国内镜像并标注。
- 进入状态页自动检查更新。
- 排版细修：Node 安装模式独立一行，版本升级四列定宽。

## 1.8.5

- 修复迁移误报「服务无响应」：后台子 shell 的 stdio 接到 `/dev/null`，请求立即返回。
- 修复百度网盘登录失败：按帮助信息决定是否传 `--accept-disclaimer`。
- 重做共享样式表，修复真机上键值被折成一字一行的问题。

## 1.8.4

- 网关不再可能以 root 运行：运行用户不存在时拒绝启动。
- 网盘组件安装器加入 sha256 校验锚点，不匹配拒绝执行。
- Node.js 下载改为 fail-closed，拉不到校验清单即中止。
- 可执行文件下载只接受 https。
- 网关 token 不再随页面加载返回，只给掩码。
- 登录状态判定改为"必须有正面证据"。
- 加密备份的 auth tag 回填改为原子操作。
- crontab 备份移出 `/etc/crontabs/`，避免被 crond 当成用户名加载。
- 定时任务脚本路径不再写死，不可执行则拒绝写入。
- 远端轮转统一按秒级时间戳排序，不再误删最新备份。
- 日志加上限 256 KB；版本号校验收紧；wget 也会走代理。
